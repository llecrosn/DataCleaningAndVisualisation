# DataCleaningAndVisualisation

Dataset description:
This dataset contains processed bacterial 16S rRNA gene and fungal ITS amplicon data generated from surface soil samples collected across four fire-severity classes—unburned, low, moderate, and high severity—at 1 month and 1 year after fire in a subtropical Pinus massoniana forest. The dataset includes eight ASV abundance matrices corresponding to the fire-severity × post-fire-stage combinations and a combined bacterial–fungal taxonomic annotation table from domain to species level. The data support the microbial community composition, diversity, and association-network analyses reported in the related manuscript.
